# ERA Residence — Homepage Rebuild

A 1:1 match rebuild of the [ERA Residence](https://www.era-residence.com/) homepage.

---

## 🚀 Quick Startup

### 1. Prerequisites
- **Node.js** (v18 or newer) — [Download Node.js](https://nodejs.org/)

### 2. Start the Server
Open your terminal in this directory and run:

```bash
npm start
```
*(Alternative: `node serve.js`)*

### 3. Open in Browser
Visit:
```
http://localhost:3000/
```

## 🧪 Optional: Run Visual Tests

To run the automated Puppeteer verification script:

```bash
npm test
```
